            Decommission Node
          

          

            

              This will remove all CA configuration, certificates, keys, and CRLs from this node,
              returning it to the setup wizard. The current configuration will be archived before removal.
            

            

              Warning:
              
                This action is irreversible. If this is a Root CA, all subordinate CAs that depend on it will be orphaned.
                If this is an Intermediate CA, any Issuing CAs signed by it will lose their chain of trust.
                Make sure you have backups of any certificates or keys you need before proceeding.
